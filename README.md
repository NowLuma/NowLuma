# Nowluma

> 基于 **SnowLuma（SL）** 二次开发。

连接真实 QQ 客户端，向机器人程序提供 OneBot v11 接口，并管理账号、连接和运行日志。
QQ 登录始终由 QQ 自己完成；程序不会另建 QQ 密码或登录令牌库。Docker 会保留 QQ 自己的用户目录和凭据。

## Docker：运行命令，然后登录

需要 Docker Engine 和 Docker Compose v2。**不需要在主机安装 Node 或 QQ。**
在解压后的源码目录运行：

```bash
bash deploy/install.sh --docker
```

首次会构建镜像、下载官方 Linux QQ。脚本检查到服务正常运行后才会提示下一步，不会清空已有数据。
交互安装可选择仅本机/SSH 访问或局域网访问；默认端口是控制台与桌面 **5099**、OneBot HTTP **3000**、WS **3001**。桌面不单独发布端口。

1. 运行 `bash deploy/manage.sh logs` 查看控制台首次密码，打开 `http://127.0.0.1:5099`，按引导设置自己的密码。
2. 点击控制台首页或「QQ 连接」里的 **打开 QQ 桌面**。
3. 桌面使用当前控制台会话，无需另填 VNC 密码；在 QQ 窗口扫码。
4. 在 **QQ 自己的设置** 中勾选自动登录。回控制台，首页会显示当前步骤；Docker 已开启自动接入 QQ。
5. 需要机器人自动回复时，到「配置」选择 QQ 账号，设置机器人连接。监听正常不代表机器人业务已就绪。

远程服务器可在自己电脑上建立隧道，再打开上面的本机地址：

```bash
ssh -L 5099:127.0.0.1:5099 -L 3001:127.0.0.1:3001 用户名@服务器地址
```

桌面通过同源控制台认证，不会把控制台令牌或后台 VNC 密码放进 URL。退出、改密或会话失效后桌面不能继续操作。

## 日常操作：不用改配置文件

```bash
bash deploy/manage.sh start         # 构建/启动，保留数据
bash deploy/manage.sh restart       # 重启并等待健康检查
bash deploy/manage.sh stop          # 停止，不删除卷
bash deploy/manage.sh logs          # 持续查看日志
bash deploy/manage.sh doctor        # 检查进程、目录、权限和监听
```

控制台支持连接地址复制、错误显示、日志查看/导出和保存位置诊断。复制端点地址默认不带令牌、URL 凭据或查询参数；请在机器人程序里另填访问令牌。

## #nl 状态回复

发送纯文本 `#nl` 可以查看程序版本、平台和运行时长。
关闭入口：**配置 → 选择 QQ 账号 → 通用设置 → 内置状态命令开关**。
关闭的是程序自己的状态回复，不影响下游机器人自行编写的回复逻辑。
旧默认触发词会迁移为 `#nl`，其它自定义触发词和已关闭的开关保持不变。

## 为什么重启后不应该丢自动登录

Docker 固定运行用户、HOME、XDG 配置目录和主机名，完整持久化 `/home/nowluma`，包括 QQ 设置、凭据、相关用户存储和一次生成的机器 ID。
停止、重启、重新创建容器时会复用相同的数据卷；不会通过重新生成凭据来“自动登录”。

**不要用 `docker compose down -v` 重启**，它会删除卷。
本地数据保留不等于 QQ 服务端永不要求验证；若会话过期、异地验证或风控要求扫码，仍需在 QQ 窗口完成。
代码和测试不会假造登录成功，也不提供封号概率保证。

## Windows / 原生 Linux

使用对应平台的发行包：

- Windows：双击 `launcher.bat`。
- Linux：运行 `bash launcher.sh`。

启动器固定工作目录并优先使用随包 Node；Lite 版需要 Node.js `24.22.1`（24.x）或 `>=26.12.1`。
原生模式请自己打开 QQ 并勾选自动登录，不需要迁移 QQ 用户目录。
原生包的一键检查启动可运行：

```bash
bash deploy/install.sh --native --directory /发行包解压目录
```

## 保存、升级和排障

- 程序的 `config/`、`data/`、`logs/` 分别保存设置、消息/媒体和日志；QQ 的数据在 QQ 自己的用户目录。
- Docker 程序卷与 QQ 完整 HOME 卷都需要保留。升级只替换程序/镜像，不删除卷。
- 从旧程序迁移时应先备份全部数据；包名、环境变量、SDK 名称和备份应用标识已更名，不能把旧版接口名直接当成新版接口使用。
- 原生组件仅更改外部文件名，内部字节和必要的套接字 ABI 保持不变，避免这一阶段改动 QQ 接入实现。
