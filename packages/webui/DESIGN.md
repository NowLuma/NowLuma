# Console design contract

- **Stable content:** warm paper/ink tokens, quiet borders and stationary reading surfaces form the base. Business rows and document actions do not lift or scale. Existing routes, account selection, confirmations, errors, loading states and saved layouts remain functional; decorative layers never replace business content.
- **Optical chrome:** existing theme controls, compact top-bar actions, log search and short menus may use `GlassMaterial`. Its non-interactive backdrop layer sits behind unfiltered labels and focus indicators. Static refraction remains available when the user or OS prefers reduced motion; motion preference stops animation, not the optical material. Geometry is bounded to 768 × 480 CSS pixels of area, so wide, short chrome can refract while full-page surfaces cannot. Displacement rasters are at most 256 pixels on their longest side and are regenerated on relevant changes, not in a continuous render loop.
- **Renderer truth:** `refracted` means an SVG displacement map was installed for a Chromium-family user agent with CSS backdrop URL support, not that a browser pixel test passed. Safari/Firefox, unsupported or oversized surfaces and rasterization failures use `frosted`; high contrast/reduced transparency use opaque `solid`. Low-performance mode skips displacement rasterization and keeps the polished solid/frosted edge. Host-managed appearance hides the material and retains its own surface rules. Browser optical acceptance remains separate from unit tests.
- **Bounded line art:** the decorative N field contains 108 vertical strokes, quantized to 1/2/3/4 px, in small chrome regions. The login field alone opts into a continuous ±2 px, 24-second drift. The existing device-local `nowluma_login_fx` preference and pre-auth “界面有点卡顿” switch pause that drift without changing server appearance preferences. Reduced/disabled motion stops drift; low-performance mode also stops drift while keeping the static strokes.
- **Performance detection:** the automatic sampler ignores a 1.5 s warmup of measured frame time, then reads 1 s windows and latches low performance after two consecutive windows below 40 FPS. The latch is session-only, never persisted, and is cleared by reset/manual override. Low performance simplifies effects without changing the saved motion preference; explicit `high`, `low` and `disableMotion` choices keep their meaning. Hidden tabs and isolated idle gaps are excluded, and consecutive long gaps count as a genuinely slow foreground cadence.
- **Accessibility and ownership:** real labels, keyboard controls, focus rings, mascot/account imagery and failure feedback stay visible. Named palettes, custom accents/backgrounds, density, UI scale, OLED and host appearance keep their existing ownership.

Validation is frontend typecheck, lint, focused optics/material/performance/line-field/login/logs/top-bar/process regression tests, the full frontend suite and production build. Real Chromium refraction, Safari/Firefox fallback, responsive keyboard/screen-reader behavior and device FPS require independent browser validation before acceptance.
