# 调试工具

上方练习只对示例账号执行动作。先读接口说明，再填写参数；涉及发送、删除或修改的真实动作必须确认账号与目标。

![调试工具中的账号接口选择与参数输入](/images/tutorials/debug.png)

_图：示例接口调用；模拟结果不能证明 QQ 消息已投递。_

路径 `/debug`。它面向开发和排障：直接调用 OneBot 动作、构建并发送消息、观察实时活动、查接口文档。页头说明是「选择账号与接口，构建消息并查看实时结果。」，并显示「N 个账号 · N 个接口」。

## 四个工作区

| 页签     | 用途                                                   |
| -------- | ------------------------------------------------------ |
| 接口调用 | 选账号和接口，填参数并运行；支持流式与调用历史         |
| 发送消息 | 选群或好友，用 OneBot 段编写并发送消息                 |
| 活动记录 | 实时事件与调用流，可暂停、导出、搜索                   |
| 接口库   | 浏览接口签名、参数、约束与返回；「试一下」跳到接口调用 |

前三个工作区在切换页签时保持挂载，正在填的参数、消息和活动流不会因为看一眼别的页签而丢失。接口库较大，打开时才加载。

## 接口调用

1. 选「账号」和「接口」，可以搜索接口名。
2. 填「请求参数」。可以切「表单」或 JSON；无参数接口会提示「该接口无参数。」。
3. 读标记：`只读`、`有副作用`、`流式`。有副作用的调用会真实生效。
4. 点「运行调用」或「运行流式调用」。运行中可「取消」。

结果区显示「响应内容」或「实时帧」「N 帧」；失败显示原因，不会把失败包成成功。下方「历史」保存本次会话的调用记录，可重放；「清空」只清历史，不影响服务端。

参数校验会阻止明显错误：`参数 JSON 格式无效`、`参数必须是 JSON 对象`、`请选择账号`、`请选择或输入接口名称`。

上传文件等动作也可以先在「接口库」搜索，再在「接口调用」执行；上传前确认账号与目标，失败不会自动重试。

**破坏性操作**：标记为有副作用的接口在运行前会弹「确认执行破坏性操作」，写明「即将以账号 … 执行 …，该操作会真实生效且通常不可撤销。」，确认按钮「确认执行」。

## 发送消息

- 选「账号」和「目标」：群聊或私聊。
- 用 OneBot 段编写「消息内容」，右侧「内容预览」显示实际结构。
- 合并转发只能由转发节点组成；把其他段放进转发节点，否则提示「合并转发消息只能由转发节点组成…」。
- 点「发送」；有转发节点时按钮显示「发送 (合并转发)」。
- 失败显示「发送失败」；成功显示「请求完成」。这只表示请求被处理，不保证对方一定收到或机器人会继续回复。

消息为空、未选账号或未选目标时不会发送，会直接提示原因。

## 活动记录

实时显示 `调用` 与 `事件`：

| 控件        | 作用                                                |
| ----------- | --------------------------------------------------- |
| 状态        | `已连接`、`重连中`、`未连接`；主动暂停显示 `已暂停` |
| 暂停 / 继续 | 暂停只停止界面更新，不改变服务端                    |
| 导出 JSON   | 导出当前活动记录                                    |
| 清空        | 清空当前视图                                        |
| 搜索        | 按类型、账号或内容筛选；类型可选全部、事件、调用    |

客户端过慢导致丢弃时会明确显示「因客户端过慢丢弃了 N 条」，不会假装完整。

## 接口库

按分类浏览接口，搜索接口名、摘要或别名。每个接口显示：

- `只读`、`有副作用`、`流式` 标记与别名。
- 参数表：参数、类型、必填、说明、默认值与约束。
- 返回说明。

点「试一下」会把接口名带到「接口调用」并切过去，不自动执行。接口库来自调试动作目录，不是手工维护的另一份清单。

## 安全边界

- 所有调用都绑定你选的账号，不会把动作发给另一个在线账号。
- 有副作用的调用会二次确认，但确认不等于可撤销；不确定时先用只读接口。
- 这里不显示 QQ 密码，也不提供绕过登录、伪造账号或修改内核选择的入口。
- 活动记录和导出可能含账号、消息或路径；对外提供前先脱敏。
- 调试工具不改变「谁负责回复」：回复逻辑在你的机器人程序里。
