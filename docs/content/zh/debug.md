# 调试

「调试」页（`/debug`）标题是「开发者工具」，副标题「接口测试 · 消息构建 · 实时观测 · API 参考」。它是给开发和排障用的，默认对登录后的用户可见，也可以在布局编辑里隐藏。

**先说最重要的一句：这里的调用会真实生效。** 发消息就是真的发出去，踢人就是真的踢掉。没有模拟模式，没有「仅预演」按钮。

## 四个页签

| 页签 | 作用 | 是否常驻 |
| --- | --- | --- |
| 测试台 | 选账号和动作，填参数，执行，看结果 | 是（切换不丢状态） |
| 消息构建 | 可视化拼一条消息并发送给群或好友 | 是 |
| 实时活动 | 事件与动作的合并实时流 | 是 |
| API 浏览器 | 搜索动作文档，看是否有副作用，一键带参数进测试台 | 按需加载 |

## 测试台

| 区域 | 说明 |
| --- | --- |
| 账号选择 | 选择要作用在哪个账号上 |
| 动作选择 | 从可用动作列表里挑一个 |
| 参数区 | 按动作的字段生成表单；切换为 JSON 模式可以直接粘贴 |
| 执行 | 普通调用；对支持流式返回的动作会逐帧显示 |
| 结果区 | 返回码、数据、错误 |
| 历史 | 本次会话里的调用记录，可回看 |

安全提示固定显示在测试台：「调用会真实生效 (真发消息 / 真踢人等), 请谨慎。」

对非只读动作会先弹出「确认执行破坏性操作」，正文是「该操作会真实生效且通常不可撤销」。

参数字段带有语义角色（`group_id`、`user_id`、`member_id`、`message_id`、`file`、`image`、`record` 等），所以表单知道该填数字、该选文件还是该填消息段。

**示例（安全的第一次调用）**：选账号 → 选一个只读动作（例如查询登录信息）→ 执行。预期结果：结果区出现返回码与数据，历史里多一条记录。这类调用没有副作用，适合先确认链路是否通。

**示例（有副作用的调用）**：选 `send_group_msg`，填真实群号与消息内容 → 执行 → 在确认框里确认。预期结果：消息真的发到那个群里，结果区返回消息 ID。**没有撤销按钮。**

## 消息构建

用来拼一条完整的消息再发送：

| 控件 | 说明 |
| --- | --- |
| 消息段列表 | 可增删段，常见类型包括文本、图片、语音、文件等 |
| 上传 | 选择本地文件上传后得到可引用的路径；上传走独立的临时目录 |
| 目标 | 选择发送到群还是好友，并填对方 ID |
| 发送 | 真实发送 |

分片结构就是 OneBot 的「数组」消息格式，因此这里拼出来的内容与你在 [节点配置](onebot-config.md#节点对话框的每个字段) 里选「数组」时下游看到的一致。

**示例**：加一个文本段「测试：忽略这条」+ 一个图片段（上传一张小图）→ 目标是自己的小号 → 发送。预期结果：小号收到文本与图片，段顺序与列表一致。

**上传注意**：上传会占用「文件传输临时数据」空间，可在「存储管理」里清理，见 [系统设置：Nowluma 与平台](settings-runtime.md#存储管理)。

## 实时活动

一行一条，事件和动作调用合并显示，用来观察「程序正在做什么」。

| 控件 | 说明 |
| --- | --- |
| 暂停 | 停止自动滚动/追加，便于阅读 |
| 搜索 | 按文本过滤 |
| 「导出 JSON」 | 把当前视图导出为 JSON |
| 「清空」 | 清空当前视图（不影响服务端） |

**示例**：在手机上给账号发一条消息，观察实时活动里是否出现对应事件。出现说明事件链路通；不出现则去 [日志](logs.md) 用 DEBUG 级别看更细的内容。

## API 浏览器

| 元素 | 说明 |
| --- | --- |
| 搜索 | 按动作名/说明过滤 |
| 分类计数 | 按类别分组显示条目数 |
| 「只读」/「有副作用」标签 | 判断调用是否安全 |
| 「试一下」 | 把这个动作及默认参数填进测试台 |

这是最快的学习路径：先看标签，只读的随便试；有副作用的先看清参数含义再执行。

## 保存与重启语义

调试页不保存配置。它留下的是：

| 内容 | 生命周期 |
| --- | --- |
| 测试台历史 | 当前页面会话 |
| 实时活动的视图 | 当前页面会话；「清空」只清视图 |
| 上传的临时文件 | 落盘到传输临时目录，需要手动清理 |

所以刷新页面就会丢掉历史，但**已经发生的副作用不会消失**。

## 失败与恢复

| 现象 | 处理 |
| --- | --- |
| 动作列表为空 | 账号没有在线；先按 [QQ 连接](qq-connection.md) 接入 |
| 返回「未连接」类错误 | 账号掉线或端点未就绪；看节点状态 |
| 流式调用只收到几帧 | 对方或动作本身提前结束；用日志 TRACE 复现一次 |
| 上传失败 | 检查文件大小与磁盘空间；太大的文件会超时 |
| 误发了一条消息 | 没有撤回开关；只能去 QQ 客户端手动撤回（若在时限内） |
| 误踢了成员 | 无法撤销，由群管理重新邀请 |

**建议**：先在测试环境或自己的小号上验证参数，再对真实群操作。调试页不提供权限隔离，凡是你登录的账号能做的事，这里都能做。
