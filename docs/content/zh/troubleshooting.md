# 排障与失败恢复

上方练习帮助你找到诊断与错误入口。真实排障先保存错误原文，只改一个变量；不要用反复点击、删除数据或关闭安全校验代替定位。

![部署诊断中的工作目录与服务状态](/images/tutorials/deployment-diagnostics.png)

_图：示例诊断，不是某个真实账号的恢复证明。_

先确认问题属于哪一层，再去对应页面。不要用删除数据、关闭隔离或伪造成功来“修好”表面现象。

## 先看哪里

| 现象                                  | 先看                                                      |
| ------------------------------------- | --------------------------------------------------------- |
| 打不开控制台、登录失败                | 本页「登录与控制台」、[访问方式与网络](access-network.md) |
| 找不到 QQ、接入失败、要求重新确认内核 | 本页「QQ 会话与账号内核」、[QQ 会话](qq-connection.md)    |
| 桌面空白或断开                        | 本页「桌面」                                              |
| 机器人收不到消息                      | 本页「机器人连接」、[机器人连接](onebot-config.md)        |
| 消息、日志或数据库异常                | 本页「数据与存储」、[运行记录](logs.md)                   |
| 页面错乱、动效异常                    | 本页「页面与外观」                                        |

先运行：

```bash
bash deploy/manage.sh doctor
bash deploy/manage.sh logs
```

原生运行则看启动终端与 `logs/`。日志里的错误不是“安装完成”。

## 登录与控制台

- **一直「初始化中…」**：服务未启动、端口冲突或 `/api/` 被代理改写；检查进程、端口与代理。
- **「登录失败」**：确认输入的是控制台访问密码，不是 QQ 密码；2FA 开启时还要验证码或恢复码。
- **「协议状态加载失败」**：控制台无法确认说明文档状态，不会放行。检查 `/api/agreements`、反向代理与服务器时间，再「重新加载」。
- **登录后立刻掉线**：Cookie 被代理改写、Host/协议不一致或系统时间偏差；也可能刚修改了密码，其他会话已失效。
- **忘记密码/丢失 2FA**：按[恢复步骤](first-run.md#忘记密码或丢失-2fa)备份并重置 `config/webui.json`；会清除 2FA 与会话。

## QQ 会话与账号内核

| 现象                                 | 原因与处理                                                                                |
| ------------------------------------ | ----------------------------------------------------------------------------------------- |
| 「未检测到可加载 QQ 主进程」         | 打开并登录 QQ 后「刷新」；Docker 检查 `/proc`、`SYS_PTRACE` 与用户一致性                  |
| 一直「加载中」                       | 原生组件/架构不匹配或权限不足；等错误出现，不要反复点                                     |
| 停在「等待连接」                     | 用「刷新管道」重连；仍失败看端口、权限与运行记录                                          |
| 停在「等待登录」                     | 在 QQ 窗口完成扫码或密码登录，再点「已登录，检查状态」                                    |
| 已在线但机器人无消息                 | 去[机器人连接](onebot-config.md)查端点与令牌                                              |
| 「选择接入内核」没有出现             | 还没有识别真实 UIN；先在 QQ 登录，再回来选择账号。不会拿 PID 代替账号                     |
| 要求重新确认内核                     | 换了 UIN、账号身份变化或风险说明版本更新；这是按账号隔离的预期行为                        |
| 「重写内核」不可选                   | 当前未验证；没有隐藏回退，也不要伪造选择                                                  |
| 单独保存内核后仍未接入               | 保存选择不等于接入；点「加载」。开启自动连接时，已有当前确认的 UIN 可在 QQ 登录后自动接入 |
| 「本地 QQ 账号与通信通道账号不一致」 | 本地识别与通道上报不一致；重新检查登录，不会猜哪个正确                                    |
| 卸载失败                             | 按提示重启 QQ；重启不删除配置或 QQ 数据                                                   |

自动连接已打开的 QQ、已有管道重连和命令行启动都不能绕过内核确认。切换账号后不能复用上一个 PID 的确认。显式卸载的 PID 会保持手动停止，刷新或自动连接不会把它重新接入；需要再次点「加载」。

## 桌面

- **入口不显示**：服务器未报告已应用的同源桌面能力（Windows 原生、旧服务器或仅配置 VNC 地址）；不要靠填写外部地址强行打开。
- **空白/连不上**：确认控制台会话有效、首次改密与说明确认完成；反向代理必须保留 `/desktop/` 和 WebSocket 升级。
- **认证失败**：桌面复用控制台会话，不另填 VNC 密码；退出或改密后需要重新进入。
- **QQ 不自动登录**：这是 QQ 自己的行为；确认完整 HOME 卷、自动登录设置与 QQ 服务端会话，见[手动验证](data-backup.md#qq-的持久化与手动验证)。

## 机器人连接

- **连不上**：连接是否启用；地址、端口、路径、令牌是否与复制值一致。复制地址不含令牌，令牌要单独填。
- **显示「未启用」**：打开该行开关；删除不是停用。
- **显示「应用失败」**：配置已保存但热重载失败；看悬停错误与运行记录，修复后重新保存。
- **改令牌后旧机器人掉线**：这是预期的；用新令牌更新并重连。
- **账号离线时保存**：会显示「已保存，下次连接时应用」；等账号接入后再验证。
- **多个账号**：监听端口不能冲突；不要用一个正常账号判断所有账号就绪。

## 数据与存储

- **磁盘满**：先看「存储管理」空间用量，清理日志或非活动临时数据；不要删除 QQ HOME。
- **数据库准备中**：等待迁移完成；失败时看错误，程序会保留原文件并自动重试，不要启动多个实例。
- **配置损坏**：程序会报错并保留原文件；从备份恢复，不要用默认值覆盖。
- **重启后要扫码**：文件保留不等于服务端会话有效；在 QQ 窗口完成验证。
- **升级后账号消失**：确认卷/目录仍被挂载、UID 一致、没有 `down -v`。

## 页面与外观

- **布局错乱**：点工作台「恢复默认」；这只重置布局，不删数据。
- **导航项不见了**：「工作台」和「偏好设置」不可隐藏；其余项可在「工作区管理」的「调整导航」里重新显示。
- **页面进不去/样式坏**：地址后加 `?safe-mode=1` 临时禁用自定义 CSS。
- **动画太强**：分别尝试「减弱动效」「关闭全部动效」；系统减少动态效果始终优先。
- **低性能仍卡**：低性能只简化折射与位移，不承诺帧率；可关闭背景壁纸、减少部件或使用更轻的浏览器环境。
- **颜色看不清**：开启高对比模式；低对比强调色会提示恢复默认。

## 运行记录与调试

- 实时流「未连接」：检查服务与网络，点「刷新」；已读日志会保留。
- 看不到事件：清除搜索、检查级别过滤与自动滚动。
- TRACE 导出失败：确认已开启 TRACE、服务端有文件且磁盘可写。
- 调试调用失败：保留错误原文；有副作用的接口先确认账号和参数，失败不会自动重试。

## 恢复矩阵

| 操作                     | 影响范围                     | 可逆性                       |
| ------------------------ | ---------------------------- | ---------------------------- |
| 「恢复默认」布局         | 工作台布局与部件设置         | 可重新编辑，不恢复旧布局     |
| 「重置全部」界面配置     | 外观、布局、导航、自定义 CSS | 不可撤销；账号与消息不受影响 |
| 移除 `config/webui.json` | 密码、2FA、会话              | 用备份可回退；账号数据保留   |
| 清理账号数据库分类       | 所选消息/媒体索引/表情记录   | 不可撤销；先备份             |
| `down -v` / 删除卷       | 全部程序数据与 QQ HOME       | 不可撤销；不要用于升级       |
| 卸载 QQ 注入             | 当前会话断开                 | 可重新加载；配置与数据保留   |

无法判断时先停服务、备份，再只改一处。把实际命令、退出状态和错误原文记录下来，比反复重试更有用。
