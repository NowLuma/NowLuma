# 偏好设置：外观与账号

在上方练习先切换主题，再选择动效与玻璃材质。它们是不同的手动偏好；改变材质不会替你开关动效。

![外观分类中的主题与显示偏好](/images/tutorials/settings-appearance.png)

_图：教学设置可随时重置，不修改真实控制台的外观或访问密码。_

路径 `/settings`。十个分类通过文档式索引切换，当前分类写入地址的 `?tab=`，可以直接分享或收藏；窄屏索引自动换行。

| 分类       | 内容                                                     |
| ---------- | -------------------------------------------------------- |
| 外观       | 主题、配色、背景、排版、顶栏、手动动效与玻璃材质、无障碍 |
| 数据与格式 | 轮询间隔、登录后落地页、时间格式                         |
| 账号安全   | 访问密码、2FA、退出登录                                  |
| 全局配置   | rkey 回退、视频上传连接数、音乐签名服务                  |
| 存储管理   | 空间用量、日志保留、临时数据与账号数据库清理             |
| 通知       | 去抖窗口、通知渠道                                       |
| 服务       | WebUI 监听、QQ 桌面、TLS、配置备份、运行环境             |
| 高级       | 自定义 CSS、界面配置导入导出与重置                       |
| 开发者     | 重新进入引导、触发崩溃界面                               |
| 关于       | 版本、更新、许可与反馈                                   |

大部分外观改动立即生效并自动保存；服务级设置会明确写出是否需要重启。下面先讲外观与账号，其余分类见[偏好设置：运行与服务](settings-runtime.md)。

## 外观

### 主题与配色

- 「主题」：浅色、深色、跟随系统。
- 「配色方案」：默认或 Catppuccin。Catppuccin 自带明暗，选择后「显示模式」「深色强度」不再改变它的明暗。
- 「深色强度」：纯黑适合 OLED，只在深色模式可见。
- 「导航样式」：跟随背景、浅色面板或强调色。
- 「显示模式」「显示密度」：舒适或紧凑。

设置说明会提示改动立即生效并保存到服务器，跨设备同步。若界面由宿主接管，会显示「外观跟随…」，原有配色与背景保留，退出集成后恢复。

### 强调色

「强调色」影响按钮、链接与高亮：

- 可选预设色，也可用「自定义颜色」。
- 「应用范围」可选「全局」或「仅导航」；仅导航时主区域保持默认色。
- 若对比度低于约 3:1，会提示「强调色对比度较低」，可「恢复默认色」或「仍然使用」。提示每次会话只出现一次，不会阻止你保留选择。

### 背景

「背景」支持纯色、渐变或壁纸，显示在卡片之间与登录页。壁纸支持 PNG / JPEG / WebP，最大 5 MB；可调「遮罩强度」与「背景模糊」，提高前景可读性。移除壁纸不会删除其他外观设置。

### 排版与界面

- 「界面字体」「等宽字体」：等宽字体用于日志与代码；可以读取本机字体，失败会提示权限问题。
- 「圆角」「界面缩放」：缩放适合高分屏或视力需要。
- 「显示密度」：舒适或紧凑。
- 「主题微调」：逐个覆盖页面背景、主文字、卡片背景、主色调、次要文字、边框、导航背景、危险/错误、成功、警告十个变量；未设置的保持配色默认值，可「全部恢复默认」。

### 顶栏

可分别关闭「连接状态」「主题菜单」「展示模式」。页面标题、工作区管理和退出登录始终保留。这里的开关只影响显示，不影响登录或连接。

### 右键菜单

「自定义右键菜单」默认开启；关闭后立即恢复浏览器原生菜单。

### 交互与无障碍

| 设置         | 作用                                                     |
| ------------ | -------------------------------------------------------- |
| 自定义光标   | 使用主题化自适应光标，默认关闭                           |
| 动效         | 手动开启或关闭，关闭后保留静态玻璃                       |
| 玻璃材质     | 手动选择完整玻璃或磨砂玻璃，不自动降级                   |
| 减弱动效     | 系统或手动辅助偏好，减少位移与弹簧                       |
| 高对比模式   | 加强边框与次要文字对比度                                 |
| 显示导航说明 | 宽屏浮动导航中显示每个页面的用途；保存为 `sidebarPinned` |

动效开关与玻璃质量独立：完整玻璃可以保持静态，磨砂玻璃也可以有动效。系统减少动态效果、减少透明和高对比是辅助约束，不是帧率自动设置。

### 显示效果

- **完整玻璃**：支持的 Chromium 使用真实背景位移折射；文字和焦点层不经过滤镜。
- **磨砂玻璃**：跳过位移贴图，保留可读的磨砂边缘与手动动效。
- **动效**：立即开启或关闭；只由你在首次设置和外观页面选择，不持续检测 FPS。

选择保存到现有界面配置并跨设备同步；旧自动质量值迁移为完整玻璃，既有关闭动效、配色和其他偏好保留。质量选择不影响消息、账号或网络。

玻璃效果本身有降级：高对比模式、系统「减少透明」或宿主接管时使用实色；Chromium 且支持背景滤镜时才做折射，其他浏览器使用霜面。只有小面积顶栏/控件使用折射，不给整页加滤镜。

## 数据与格式

- 「轮询间隔」：定期刷新账号、进程与系统信息；可选暂停。
- 「默认页面」：登录后打开哪个页面，选项来自六个导航项。
- 「时制」：24 小时制或 12 小时制。

这些是界面偏好，自动保存，立即生效。

## 账号安全

控制台只有一个本地账号 `admin`。密码以 scrypt 哈希保存到 `config/webui.json`，不会保存明文。

- 「访问密码」→「修改密码」：需要当前密码和两次新密码；成功后其他设备的会话立即失效。
- 「退出登录」：清除当前浏览器会话，不影响其他设备。
- 忘记密码时的恢复步骤见[首次启动](first-run.md#忘记密码或丢失-2fa)。

## 双重验证

「双重验证」默认关闭。开启后登录需要密码加一次性验证码。

1. 点「开启 2FA」，用 Authenticator 扫描二维码，或复制密钥手动添加。
2. 输入当前访问密码和 6 位验证码，点「确认开启」。
3. 保存显示的恢复码；它们只显示一次，丢失 Authenticator 时用它们登录。

| 操作                 | 说明                                         |
| -------------------- | -------------------------------------------- |
| 「重新生成」恢复码   | 需要当前密码和验证码，旧码立即作废           |
| 关闭 2FA             | 需要当前密码以及验证码或恢复码；其他会话失效 |
| 登录时「使用恢复码」 | 每个恢复码只能用一次，连字符自动忽略         |

恢复码剩余数量显示在「账号安全」的 2FA 行。不要把恢复码和密码放在同一个地方。

## 保存与生效

| 项目              | 保存方式                       | 生效                 |
| ----------------- | ------------------------------ | -------------------- |
| 外观、数据与格式  | 自动保存到服务器               | 立即，跨设备同步     |
| 访问密码、2FA     | 提交后写入 `config/webui.json` | 立即；相关旧会话失效 |
| 界面配置导入/导出 | 手动                           | 导入后重新载入界面   |

保存失败会保留当前界面状态并提示原因，不会用默认值覆盖你的配置。
