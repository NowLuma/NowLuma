# 偏好设置：运行与服务

先在上方练习找到「服务」与运行目录诊断，再区分保存配置和重启后生效。修改真实监听地址前，保留一个能回退的访问入口。

![服务分类中的监听与运行环境设置](/images/tutorials/settings-service.png)

_图：示例服务配置；教学保存不会改变设备监听或 TLS。_

这些分类决定服务怎么运行、数据保留多久、通知发到哪里，以及怎么更新。外观与账号见[偏好设置：外观与账号](settings-console.md)。

## 全局配置

对所有账号生效：

| 设置             | 作用                                                             |
| ---------------- | ---------------------------------------------------------------- |
| rkey 回退        | 内核取不到 rkey 时依次请求的服务列表；留空关闭，建议自建         |
| 视频上传连接数   | 1–4 路，对下一次上传生效；小视频仍单连接，提速取决于网络与服务器 |
| 音乐分享签名服务 | 音乐卡片签名地址；留空使用内置服务                               |

保存成功显示「全局配置已更新」；无效项会被忽略并明确提示，不会静默当成全部成功。配置文件在 `config/`，不需要改账号数据库。

## 存储管理

「空间用量」显示日志、账号数据库与传输临时数据的总量；「日志」显示文件数、活动文件与丢弃行数。

### 日志保留

- 「日志总量上限（MB）」：必须大于 0，始终生效。
- 「保留天数」：`0` 表示只按总量淘汰。
- 「按账号额外写入日志」：开启后同一条带账号上下文的日志还会写入账号子目录，占用增加。
- 点「保存并应用」立即生效，不需要重启。

### 清理临时数据

| 项目             | 行为                                           |
| ---------------- | ---------------------------------------------- |
| 日志             | 先轮转活动文件，再删除旧日志，保留新建空文件   |
| 文件传输临时数据 | 删除非活动文件；正在上传或下载的项目保留       |
| 账号数据库       | 按账号和分类清理：消息历史、媒体索引、表情回应 |

账号数据库清理只删除所选分类及边车文件，不删除配置、凭据或聊天内容导出。账号在线时不能清理它的数据库；「全部账号」清理要求所有账号离线，并输入确认短语。删除不可撤销，先备份。

## 通知

「去抖窗口（秒）」控制上下线通知：下线持续超过该时长才通知，恢复时再通知；`0` 表示立即通知。

「通知渠道」支持 Webhook 和邮件。新增渠道需要渠道 ID、显示名，以及：

- Webhook：URL、可选请求头。
- 邮件：SMTP 主机、端口、用户名、授权码/密码、发件人、收件人、主题模板。

每行可以启用、测试发送、编辑或删除。「测试发送」只验证渠道本身，不代表某个账号的上下线事件一定会送达。渠道保存后，还要到「机器人连接 → 消息行为 → 上下线通知渠道」为账号勾选。

## 服务

### 服务监听

- 「端口」：WebUI 监听端口，默认 `5099`。
- 「绑定地址」：`127.0.0.1` 仅本机，`0.0.0.0` 所有网卡；页面会提示局域网访问应配 HTTPS 与强凭据。
- 「信任代理 (trust-proxy)」：只有位于受信任反向代理后才设置。
- 「自动连接已打开的 QQ」：保存后重启生效。开启后，只有本地 QQ 已登录、真实 UIN 已识别，且该 UIN 已有当前风险版本的兼容内核确认时，才会自动接入；这不是 QQ 自动登录，也不会跳过内核确认。显式卸载的 PID 仍保持手动停止，刷新或自动连接不会重启它。

保存监听设置后按提示重启 Nowluma。

### QQ 桌面

- 「noVNC 端口」「桌面地址（可选）」仍会保存，但自动的「打开 QQ 桌面」入口不再由这两个字段单独决定；只有服务器实际应用了同源桌面网关时才会出现。
- 自动入口始终使用同源 `/desktop/`，不会根据浏览器 UA 判断，也不会跳到配置里的外部地址。
- 该能力只在应用了网关的 Linux 服务器上为真；Windows 原生即使配置了 VNC 地址也不显示入口。从 Windows 浏览器连接 Linux Docker 服务器时仍可使用。
- 桌面复用当前控制台会话，不需要另填桌面密码；QQ 扫码与自动登录仍在 QQ 窗口里完成。

### HTTPS / TLS

启用前安装有效的 PEM 证书与私钥。私钥只写入 `config/key.pem`（0600），不会回显；证书无效会拒绝保存。启用 TLS 后若证书无法加载，WebUI 不会降级为 HTTP，而是启动失败——这是为了避免把本该加密的访问悄悄降级。

### 服务配置备份

备份外观、服务设置与证书；不包含消息数据库。通知渠道、OneBot 配置和账号内核选择（`kernel-selections.json`）只在开启「导出时包含敏感配置」时一并导出；不开敏感项时跳过这些文件，不会隐含风险同意。

- 导出敏感配置会额外包含 WebUI 登录状态、TLS 私钥、渠道地址、OneBot 令牌与按 UIN 的内核选择，需妥善保管。
- 恢复内核选择时严格解析文档；格式损坏、假确认或无效 UIN 会拒绝恢复，写入权限为 0600。旧风险版本或重写内核选择会原样保留，但不会因此获得接入授权。
- 恢复时若也恢复敏感配置，会覆盖当前登录状态、私钥、渠道与令牌；忘记备份口令可能登不进去。不含内核选择的旧备份仍然有效。
- 恢复前会校验并自动回滚失败写入；成功后需重启生效。服务配置快照只替换期望配置，不会热改运行中的内核授权或进程状态。

### 运行环境与保存位置

显示程序工作目录、服务 HOME、配置/消息媒体/日志目录及可写状态，可「复制诊断」。这里不导出令牌、密码或 QQ 登录库。

## 高级

「自定义 CSS」登录后应用，不影响登录页；最多 50000 字符。出现样式问题时在地址后加 `?safe-mode=1` 临时禁用。

「备份与重置」导出或导入外观、布局与自定义 CSS（上限 256 KB），背景图片需重新上传；「重置全部」会把外观、仪表盘布局、导航与自定义 CSS 恢复默认，不可撤销。重置不删除账号、消息或连接配置。

## 开发者

- 「重新进入」：以演练模式重走首次使用引导，不修改说明确认记录或真实密码。
- 「触发崩溃」：主动抛出测试异常，交给页面错误边界；在崩溃界面点「重试」返回。

这两个按钮始终可见，不受环境开关影响，但只用于界面测试。

## 关于

显示当前版本、检查更新与更新状态：

- 「重新检查」查询最新版本；关闭检查时显示「检查已关闭」。
- 「更新来源」：自动切换、GitHub 直连或指定镜像；自动模式先试 GitHub，再按候选顺序切换。可「检测可用性」并「保存来源」，检测结果不代表下载速度。
- 有更新时可「下载更新」；下载就绪后「重启并更新」，连接会暂时断开，配置与数据保留。

「项目与许可」提供源码、发行版、问题反馈和 GPLv3 链接，并写明允许商业使用、第三方与原生组件遵循各自许可。侵权投诉邮箱只用于侵权投诉；一般使用、商业合作或隐私问题不要发到那里。

更新检查会访问网络，但当前源码没有分析或遥测上报；详见 `PRIVACY.md`。

## 保存与重启

| 项目                                     | 保存后                                                    |
| ---------------------------------------- | --------------------------------------------------------- |
| 全局配置、通知、存储日志策略             | 立即应用，通常不需要重启                                  |
| WebUI 端口、绑定地址、信任代理、自动连接 | 重启 Nowluma 后生效                                       |
| QQ 桌面入口                              | 由服务器实际网关能力决定；配置端口/地址不会单独让入口出现 |
| TLS 证书                                 | 重启后按新证书启动                                        |
| 配置备份恢复                             | 重启后生效                                                |
| 更新                                     | 重启并更新后生效                                          |
