# 机器人连接

在上方练习先选账号，再打开一种连接并修改示例配置。观察「已保存」和「已应用」是否一致；真实地址与令牌只填进你自己的控制台。

![示例账号的机器人连接配置页](/images/tutorials/connection.png)

_图：教学连接仅存在于内存，不会打开实际监听端口。_

路径 `/config`。这一页按账号管理两件事：消息行为，以及机器人程序如何连上来。页头说明是「按账号管理连接方式与消息行为，改动自动保存。」。

这里配置的是 OneBot 端点，不是 QQ 登录。QQ 登录始终在 QQ 窗口完成。

## 页面结构

1. 顶部账号条：显示已接入的 QQ，点一个切换；未选账号时不能编辑。
2. 分类页签：`消息行为`、`HTTP 接口`、`HTTP 推送`、`WebSocket 监听`、`反向 WebSocket`。
3. 编辑区：标题、`UIN …`、保存状态、`添加连接`、`立即保存`。
4. 连接列表：名称、格式、令牌状态、地址摘要、实时状态与操作。

切换账号时如果当前页还有未保存修改，会先问「放弃未保存的修改？」，确认「放弃并切换」后才换。修改不会悄悄写到另一个账号。

## 消息行为

「消息行为」页签包含三组设置。

### 登录与记录

「登录时同步云端历史」补齐最近会话的本地历史。每次最多同步 3 个群和 3 个好友、各 20 条，自动请求间隔至少 2 秒；只写入本地历史，不重放事件、不改变已读状态。下次登录或重启生效。

### 状态回复

| 控件                 | 说明                                                                   |
| -------------------- | ---------------------------------------------------------------------- |
| 「启用状态回复」     | 收到触发词时回复版本、平台与运行时长；任何人均可触发，关闭后完全不响应 |
| 「触发词」           | 默认 `#nl`，最长 32 字符；匹配忽略首尾空格与大小写                     |
| 「回复冷却（秒）」   | 同一会话冷却期间不重复回复，`0` 表示不限                               |
| 「拦截已命中的消息」 | 不再转发给下游 Bot，仍会回复并记录                                     |

状态回复的改动和其他消息行为一样，停止输入约半秒后自动保存。

### 通知选择（opt-in）

「上下线通知渠道」默认折叠，显示「已选 N / 共 M」：

- 展开后可以搜索、逐个开关，或点「全选」选中所有已启用渠道。
- 渠道本身在「偏好设置 → 通知」里全局定义；这里只决定当前账号的上下线事件发给哪些渠道。
- 没有全局渠道时提示「还没有全局渠道——先到「设置 → 通知」添加。」；没有选择时显示「未选择任何渠道。展开以选择。」。
- 被删掉的旧渠道 id 会保留在已选集合末尾，不会因为列表变化而误删其他选择。

## 四个连接页签

| 页签           | 用途                                  | 新连接默认                                     |
| -------------- | ------------------------------------- | ---------------------------------------------- |
| HTTP 接口      | 在本机提供 HTTP 接口，供 Bot 程序调用 | `127.0.0.1:3000`，路径 `/`，可加 WebSocket/SSE |
| HTTP 推送      | 主动向指定 HTTP 地址推送事件          | `http://127.0.0.1:5700`                        |
| WebSocket 监听 | 在本机监听，等待 Bot 程序连接         | `127.0.0.1:3001`，角色 `Universal`             |
| 反向 WebSocket | 主动连接 Bot 程序的 WebSocket         | `ws://127.0.0.1:8080/ws`，重连 5000 ms         |

每个页签下方都提示「复制地址不含令牌，请在机器人程序中单独填写。」。页签次序固定，计数徽章显示该类型已有多少个连接。

## 连接列表

每一行显示：

- 名称；空名称显示「(未命名)」，重名会标「名称重复」并阻止保存。
- 「数组」或「CQ 码」、「含自身消息」或「不含自身消息」、「令牌已设置」或「未设令牌」。
- 地址摘要，以及实时状态：`运行中`、`待检查`、`未连接`、`应用失败`、`未启用`。
- 操作：启用开关、「编辑」、复制地址、删除。

「应用失败」表示配置已保存，但热重载没有成功；把鼠标停在状态上可以看到最近错误与时间。

空类型显示「还没有…连接」和「添加连接」。删除会确认「删除连接 …？」并说明只停止这一条连接，其他连接与消息记录不受影响。

## 节点对话框的每个字段

新建和编辑共用同一个对话框，标题为「新建 …」或「编辑 …」。

| 分组 | 字段                                                                                                                    |
| ---- | ----------------------------------------------------------------------------------------------------------------------- |
| 连接 | 「启用」、名称、「消息格式」（数组 / CQ 码）                                                                            |
| 鉴权 | 「授权 Token」，可生成随机令牌、复制或显隐                                                                              |
| 行为 | 仅监听类有「启用 WebSocket」「启用 SSE」；WebSocket 有「角色」（Universal / Event / Api）；所有连接都有「上报自身消息」 |
| 地址 | 主机、端口、路径，或目标 URL；HTTP 推送还有超时，反向 WS 还有重连间隔                                                   |
| 高级 | WebSocket 单帧上限（bytes）                                                                                             |

默认主机 `127.0.0.1` 只允许本机连接；填 `0.0.0.0` 前请确认防火墙和令牌。名称重复会提示「名称与其它节点重复」，未填名称提示「请填写名称」；保存中按钮显示「保存中…」。

新建按钮写「添加连接」，编辑写「保存连接」。对话框只有在提交成功后关闭，失败原因留在对话框里。

## 保存与生效

| 操作                       | 保存方式                     | 结果                                                 |
| -------------------------- | ---------------------------- | ---------------------------------------------------- |
| 修改消息行为               | 停止输入约 500 ms 后自动保存 | 成功不弹窗；失败显示原因，不自动重试                 |
| 新建、编辑、删除、启停连接 | 立即写入                     | 成功显示「已保存并应用」或「已保存，下次连接时应用」 |
| 「立即保存」               | 立即提交当前配置             | 用于不想等待防抖时                                   |
| 账号离线                   | 仍可保存                     | 显示「已保存，下次连接时应用」，等账号下次接入       |

在线时热重载成功，才显示「已保存并应用」；部分失败会写「已保存，但热重载失败：…」，服务端尽量恢复旧端点。失败不会被说成成功，也不会盲目重试不确定的写入。

**示例**：选账号 → HTTP 接口 → 添加连接 → 端口 `3000`、路径 `/onebot`、生成令牌 → 添加连接 → 预期状态「已保存并应用」 → 复制地址（不含令牌），把地址和令牌分别填进机器人程序。

## 令牌与地址

- 复制按钮只复制连接地址，不含令牌或查询参数；令牌要在机器人程序里单独填写。
- 修改令牌会断开用旧令牌连上的机器人程序，这是预期行为；更新机器人配置后重连。
- 宿主名、端口、路径、令牌任何一项不一致，机器人都会连不上。
- 监听成功不等于机器人已连接，更不等于它会自动回复。

## 排障

| 现象                   | 检查                                                 |
| ---------------------- | ---------------------------------------------------- |
| 机器人连不上           | 连接是否启用；地址、端口、路径、令牌是否与复制值一致 |
| 显示「未启用」         | 打开该行开关；删除不是停用的替代品                   |
| 显示「应用失败」       | 看悬停错误与运行记录；修复后重新保存                 |
| 改了令牌后旧机器人掉线 | 用新令牌更新机器人配置                               |
| 账号切不过去           | 先处理「放弃未保存的修改？」                         |
| 页签为空               | 当前账号没有这种连接；点「添加连接」                 |
