# 运行记录

先在上方练习筛选与搜索，再查看某条完整错误。导出前确认日志是否包含账号或令牌；清空当前视图与清理磁盘日志不是同一个操作。

![运行记录的实时流和筛选控件](/images/tutorials/logs.png)

_图：示例事件流；级别文字与错误内容比颜色更重要。_

路径 `/logs`。它显示控制台和接入层的实时事件，用来回答「刚才发生了什么」。页面本身不改变 QQ 连接，也不会自动修复错误。

## 实时流

页头显示流状态：`实时`、`连接中`、`重连中` 或 `未连接`，以及当前过滤后的条数。实时流断开时会提示，并保留已经读到的日志；错误行不会被隐藏。

日志行按级别着色：`TRACE`、`DEBUG`、`INFO`、`SUCCESS`、`WARN`、`ERROR`。级别文字与颜色只是辅助，搜索和过滤仍按文本工作。

## 视图预设

| 预设   | 内容                                     |
| ------ | ---------------------------------------- |
| 开发   | 全部级别、2000 行、自动滚动、自动换行    |
| 运维   | INFO 以上、1000 行                       |
| 精简   | 仅 WARN/ERROR、500 行                    |
| 自定义 | 你手动改过任一项后显示，不再对应固定组合 |

预设会保存到页面偏好，刷新后保留。切换预设会一起调整可见级别、行数、自动滚动与换行。

## 级别过滤

级别按钮可以多选；全部关闭时不会显示日志。过滤只改变视图，不删除服务端日志。

## 搜索与显示选项

搜索框提示「搜索消息 / 模块 / 级别」，旁边可以一键「清除搜索」。右侧工具栏：

| 按钮     | 作用                                           |
| -------- | ---------------------------------------------- |
| 自动滚动 | 在「自动滚动已开启」「自动滚动已暂停」之间切换 |
| 自动换行 | 长行折行；关闭后横向滚动                       |
| 显示选项 | 展开服务端级别与高亮规则                       |

自动滚动只在你停留底部时跟随；向上翻看时不会强行拉回。

### 高亮规则

在「显示选项」里添加「高亮关键词」，选择颜色：琥珀、玫瑰、翡翠、天蓝、紫。规则最多 20 条，刷新后保留；删除规则不会删除日志。

高亮只改变匹配关键词的底色，不改变过滤结果。

## 服务端日志级别与 TRACE

「服务端日志级别」控制服务端写日志的详细程度：

- 普通日志只影响控制台与实时流；首次登录凭据只输出到启动终端。
- 写入文件的等级由环境变量决定，默认 `debug`。
- 切换级别会请求服务端确认，失败时显示「日志级别更新失败」并保留原值。

选择 `TRACE` 会先弹出「开启 TRACE 日志？」，列出风险；确认按钮是「开启 TRACE」。开启后页面顶部出现红色提示「TRACE 已开启：正在记录大量、可能未经脱敏的数据」，可点「恢复 INFO」立即降回。

不要把 TRACE 长期开着，也不要把含账号数据的日志直接发到公开渠道。

## 导出与清空

| 按钮               | 结果                                                           |
| ------------------ | -------------------------------------------------------------- |
| 「导出当前视图」   | 导出当前过滤后的日志文本；没有内容时不可用                     |
| 「导出完整 TRACE」 | 读取服务端 TRACE 文件；可能较慢，失败会提示「TRACE 导出失败」  |
| 「清空视图」       | 确认「清空当前日志视图？」后只清浏览器视图，不影响服务端缓冲区 |

清空后新日志仍会继续进入；想保留证据时先导出。

## 保存与生效

| 项目                               | 保存方式           | 生效                           |
| ---------------------------------- | ------------------ | ------------------------------ |
| 预设、级别、搜索、滚动、换行、高亮 | 页面偏好，自动保存 | 立即，刷新后保留               |
| 服务端日志级别                     | 服务端设置         | 立即；文件级别仍由环境变量决定 |
| 清空视图                           | 当前浏览器         | 立即，不落盘                   |

## 排障

- **没有日志**：确认实时流状态；「未连接」时检查服务与网络，再点「刷新」。
- **日志太多**：切到「运维」或「精简」，或关闭部分级别。
- **看不到刚发生的事件**：清除搜索或检查级别过滤；自动滚动暂停时手动滚到底。
- **TRACE 文件导出失败**：确认服务端已启用 TRACE，并检查磁盘权限。
- **颜色看不清**：高亮和级别颜色不是唯一信息，文本级别仍显示；可在外观里开启高对比模式。
