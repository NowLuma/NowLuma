# 日志

「日志」页（`/logs`）是排障的主要入口。它通过 SSE 实时接收服务端日志，并在浏览器里做过滤、高亮和导出。

## 页头与实时状态

- 标题「运行日志」。
- 一个状态点：`实时` / `连接中` / `重连中`。
- 计数行：`{过滤后}/{总数} 条 · SSE 实时推送 · 服务端 {LEVEL}`。

「服务端 {LEVEL}」显示的是服务端当前记录级别，和你本地勾选的显示级别是两件事。服务端级别决定**产生**什么，本地过滤只决定**看到**什么。

## 工具栏

| 控件 | 作用 | 保存 |
| --- | --- | --- |
| 搜索框（提示「搜索消息 / 模块 / 级别」） | 全字段匹配 | 不保存（本次会话） |
| 「清除搜索」 | 清空搜索词 | — |
| 「自动滚动已开启」/「自动滚动已暂停」 | 新日志是否自动滚到底部 | 是（页面偏好） |
| 「自动换行」 | 长行是否折行 | 是 |
| 「显示选项」 | 展开预设、服务端级别、高亮规则 | 展开状态不保存 |
| 「刷新」 | 重新拉取最近日志 | — |
| 「导出当前视图」 | 导出**当前过滤结果**为 `.log` 文件，纯浏览器侧生成 | — |
| 「导出完整 TRACE」 | 让服务端导出完整的 TRACE 文件 | — |
| 「清空视图」 | 清空浏览器里的日志视图 | — |

两个导出不是一回事：「导出当前视图」受你的搜索和级别过滤影响；「导出完整 TRACE」是服务端文件，内容更全。

「清空视图」的确认框写明：「此操作仅清空浏览器视图中的日志，不会影响服务端的日志缓冲区。」也就是说清空后刷新还能再拉回来。

## 级别过滤

六个级别开关：`TRACE`、`DEBUG`、`INFO`、`SUCCESS`、`WARN`、`ERROR`。关掉的级别不显示，但仍可能被服务端记录。

## 视图预设

「显示选项」里有三套预设，加上自定义：

| 预设 | 级别 | 最大行数 | 换行 |
| --- | --- | --- | --- |
| 开发 | 全部级别 | 2000 | 开 |
| 运维 | INFO 及以上 | 1000 | 关 |
| 精简 | WARN + ERROR | 500 | 关 |
| 自定义 | 你自己勾的 | 自定 | 自定 |

最大行数是浏览器里保留的上限，超出后最旧的行被丢弃，避免长时间打开标签页把内存吃满。

## 服务端日志级别

面板里可以切换服务端级别，旁边明确写着：普通日志仅影响控制台和实时流，文件等级由环境变量决定，默认为 `debug`。

**换句话说**：改这里只改变控制台/实时流记录得有多细，不会改变磁盘上日志文件的级别。

## TRACE 的代价

开启 TRACE 后页面顶部会常驻一条横幅：「TRACE 已开启：正在记录大量、可能未经脱敏的数据」，并提供「恢复 INFO」。

开启前有一次性确认，列出四条警告：

1. TRACE 会产生非常大量的数据。
2. 可能包含未经脱敏的隐私数据和凭据。
3. 不适合长时间开启。
4. 仅用于小规模问题复现和 bug 反馈。

这是本文档里最需要注意的隐私事项：

- TRACE 可能把消息内容、账号标识、令牌片段写进日志。
- 导出的日志文件同样包含这些内容。分享给他人之前请自己检查并删减。
- 排查结束后立刻「恢复 INFO」，不要长期开着。

## 高亮规则

可以添加关键词高亮：

- 关键词最长 50 字。
- 五种颜色：琥珀、玫瑰、翡翠、天蓝、紫。
- 最多 20 条规则，可逐条删除。

**示例**：加一条关键词 `timeout`、颜色玫瑰，然后等一次连接超时。预期结果：命中的行整行标注玫瑰色，方便在大量 INFO 里定位。

## 视图保存与失败恢复

| 保存的内容 | 位置 | 失败表现 |
| --- | --- | --- |
| 显示级别、最大行数、自动滚动、换行、高亮规则、预设 | 页面偏好（界面配置） | 右下角「页面偏好同步失败」，本地仍生效 |

如果日志页整页空白：

1. 看页头状态点。`重连中` 说明 SSE 断了，等服务端恢复会自动重连。
2. 点「刷新」走一次普通请求，确认服务端可读。
3. 检查反向代理是否缓冲了 SSE——反代需要关闭 `proxy_buffering` 并给足读超时。
4. 用 `bash deploy/manage.sh logs` 看容器日志，确认进程还在。

## 排障用的一个完整流程

1. 先按「运维」预设（INFO 及以上）看现象。
2. 需要细节时切到 TRACE，复现一次问题，**只复现一次**。
3. 「导出当前视图」拿到这一小段，或「导出完整 TRACE」拿到完整文件。
4. 立即「恢复 INFO」。
5. 把日志里的账号、令牌、消息内容替换成占位符后再发给别人。
