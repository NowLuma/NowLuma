# 工作台

跟随上方引导找到当前会话与下一步操作，再熟悉底部六个页面入口。先读状态，再执行操作，不需要先调整布局。

![工作台连接流程和底部主导航](/images/tutorials/overview.png)

_图：工作台中的示例会话与运行读数。_

工作台是登录后的第一页，路径 `/`。顶栏标题取自当前导航项，显示「工作台」；页内主标题是「从会话，到结果」。它把连接工作流、运行读数和可编辑部件放在同一页。

## 页面结构

从上到下：

1. 顶栏：品牌、当前页面标题、连接状态、主题菜单、「工作区管理」与「更多操作」。
2. 连接工作流：固定位置，不是可拖动部件，按三个阶段告诉你下一步做什么。
3. 五个读数卡加四个内容部件，右侧入口跳到运行记录。
4. 浮动主导航：底部带文字标签的六个页面入口，是唯一的主导航。

## 顶栏与工作区管理

| 元素         | 作用                                                                             |
| ------------ | -------------------------------------------------------------------------------- |
| 页面标题     | 取自当前导航项，例如「工作台」                                                   |
| 连接状态     | 控制台会话是否可用；连接正常时显示「服务在线」，**不是** QQ 在线状态             |
| 主题菜单     | 可切换浅色或深色（含跟随系统）；只有一个主题按钮，不再有三颗图标的胶囊           |
| 工作区管理   | 直接打开右侧面板：调整导航顺序与显隐、打开隐藏的页面、进入布局编辑、查看更新提示 |
| 更多操作 `⋯` | 会话菜单，提供「展示模式」「退出登录」；退出登录始终存在                         |

「退出登录」会先弹「退出登录？」，确认后清除当前会话令牌，下次需要重新输入访问密码。

主题菜单、连接状态与展示模式可以在「偏好设置 → 外观 → 顶栏」里分别收起；页面标题、工作区管理和退出登录不会被隐藏。

## 浮动主导航

桌面和手机共用一条浮在底部的导航条，六个入口始终带图标和名称；宽屏可显示说明：

| 导航       | 路径         | 说明             |
| ---------- | ------------ | ---------------- |
| 工作台     | `/`          | 会话、连接与结果 |
| QQ 会话    | `/processes` | 选择并接入会话   |
| 机器人连接 | `/config`    | 建立机器人连接   |
| 运行记录   | `/logs`      | 查看连接结果     |
| 调试工具   | `/debug`     | 测试动作与排查   |
| 偏好设置   | `/settings`  | 外观、账号与设备 |

底部这条导航是唯一的主导航：没有折叠按钮，也不会因为鼠标悬停把内容推开。宽屏是否显示每项的说明文字，由「偏好设置 → 外观 → 显示导航说明」控制；这个开关保存为同一个 `sidebarPinned` 值，刷新后仍生效。

### 调整导航

在顶栏点「工作区管理」，再点「调整导航」：

- 拖动行或使用「上移 / 下移」调整顺序。
- 点眼睛图标切换「隐藏 / 显示」。
- 「工作台」和「偏好设置」带锁，显示「必选项，不可隐藏」；它们可以排序，但不能隐藏，避免把自己锁在布局编辑或账号设置之外。
- 隐藏的页面仍列在「隐藏的页面」里，可以从那里直接打开。
- 点「完成调整」退出编辑。导航顺序和显隐自动保存，刷新后保留。

## 连接工作流

连接工作流是一块固定区域，不是可拖动部件。隐藏所有卡片不会移除它；主动停止会话后，它不再催促重新接入，但读取失败和进行中的操作仍会显示。

顶部是「连接路径」的三个阶段：`QQ 会话` → `机器人连接` → `查看结果`。当前阶段高亮，已完成的阶段显示勾选标记。

下面是「当前 QQ」卡片和下一步提示：

- 卡片显示账号昵称或「尚未选择」，以及「已登录」「待确认」或「从会话开始」，后面跟 `QQ <UIN>` 或 `PID <pid>`。检测到多个进程时出现「更换会话」。
- 提示给出当前该做的事、一句说明和一个主按钮；全部就绪后按钮是「查看结果」，跳到运行记录。
- 「打开 QQ 桌面」只在服务器实际提供同源桌面时出现在按钮旁。

常见按钮与预期结果：

| 按钮                 | 什么时候出现                   | 结果                                               |
| -------------------- | ------------------------------ | -------------------------------------------------- |
| 「重新检查」         | 读取失败或状态没有变化         | 重新读取进程与登录状态                             |
| 「我已打开 QQ」      | 还没检测到 QQ                  | 重新读取进程列表                                   |
| 「选择 QQ」          | 检测到多个 QQ                  | 打开「选择 QQ 会话」，一次只选一个                 |
| 「重试接入」         | 接入失败                       | 对当前会话重试附加                                 |
| 「重新连接」         | 接入后连接断开                 | 重连已有管道，不重新注入                           |
| 「选择内核并接入」   | 该账号还没有当前风险版本的确认 | 打开「选择接入内核」，确认后才附加                 |
| 「已登录，检查状态」 | QQ 进程已加载但还没登录        | 重新检测登录状态                                   |
| 「配置机器人连接」   | QQ 已接入但还没有启用的连接    | 跳到「机器人连接」                                 |
| 「连接说明」         | 全部就绪                       | 说明控制台不负责自动回复                           |
| 「查看原因」         | 读取、接入或端点异常           | 打开「检查原因」，错误不会只出现在一闪而过的提示里 |

如果任一状态读取失败，面板会显示失败原因和「重新检查」，不会把失败当成成功继续。

## 布局编辑

点「编辑布局」进入编辑，按钮变成「完成编辑」；页头出现「恢复默认」。

| 操作 | 桌面                             | 手机                     |
| ---- | -------------------------------- | ------------------------ |
| 移动 | 拖动卡片                         | 拖动手柄调整单列顺序     |
| 缩放 | 拖右下角                         | 不支持，使用部件默认高度 |
| 添加 | 从右侧「卡片库」点加号或拖到画布 | 用眼睛图标显示           |
| 移除 | 把卡片拖回「卡片库」             | 用眼睛图标隐藏           |
| 设置 | 卡片右上齿轮                     | 行内齿轮                 |
| 恢复 | 「恢复默认」                     | 同一按钮                 |

桌面是 12 列自由网格，卡片不会自动挤到顶部；手机是独立的单列顺序，与桌面布局互不改写。

桌面网格支持键盘调整：选中卡片后用方向键移动，`Shift` + 方向键缩放，`Delete` 隐藏到卡片库。隐藏的卡片仍可从「卡片库」重新添加。

**保存与恢复**：布局、部件设置和手机顺序自动保存到界面配置，刷新后保留。保存失败时保留本地状态并提示「界面布局同步失败」；需要回到初始摆法时点「恢复默认」，这只重置布局，不删除账号、连接或数据。所有卡片都隐藏时，空状态显示「所有工作台卡片都已隐藏」和「恢复默认布局」。

## 部件一览

| 部件       | 默认可见 | 内容                                                          |
| ---------- | -------- | ------------------------------------------------------------- |
| 控制台连接 | 是       | 控制台是否「服务在线」；否则显示当前状态                      |
| 已登录会话 | 是       | 已接入会话数；读取失败时显示 `—` 或「更新失败，显示上次数据」 |
| QQ 程序    | 是       | QQ 进程总数，附「已接入 / 未接入」计数，可跳到 QQ 会话        |
| 运行设备   | 是       | 主机名、系统与架构，可查看完整信息                            |
| 连续运行   | 是       | 系统运行时长与服务进程运行时长                                |
| 机器人连接 | 是       | 各账号端点的实时状态与筛选                                    |
| 运行动态   | 是       | 最近的告警与错误                                              |
| 资源用量   | 是       | CPU、内存、运行进程、堆内存、外部内存                         |
| QQ 会话    | 是       | 在线账号的会话列表                                            |
| 便签       | 否       | 最多 4000 字的本地备忘                                        |
| 链接卡     | 否       | 标题与 http/https 链接                                        |
| 账号快捷卡 | 否       | 指定 UIN 的摘要                                               |
| 通知投递   | 否       | 最近的上线/下线通知投递记录                                   |

读数卡只显示真实数据：读取失败且没有缓存时显示 `—`，有缓存时标明「更新失败，显示上次数据」。这里没有虚构的在线数或 FPS 指标。

### 可配置部件

| 部件                       | 可调项                                               |
| -------------------------- | ---------------------------------------------------- |
| 运行动态                   | 显示条数、显示级别                                   |
| QQ 会话                    | 排序（最近 / UIN / 昵称）、筛选                      |
| 资源用量                   | 显示的指标：CPU 使用率 / 内存使用 / 运行进程         |
| 机器人连接                 | 排序（默认 / 名称 / 异常优先）、仅显示异常端点、筛选 |
| 便签 / 链接卡 / 账号快捷卡 | 各自内容；链接只接受 http/https                      |

关闭「资源用量」的全部指标时，界面会回退为全部显示，避免留下一张空卡。

## 展示模式

- 入口：顶栏「更多操作」里的「展示模式」，或地址加 `?kiosk=1`。
- 退出：按 `Esc`，或点屏幕上的退出按钮。
- 效果：隐藏顶栏、浮动导航和编辑入口，适合大屏值守；**只影响显示**，不改变认证，也不会让没登录的人看到数据。
- 状态记在浏览器会话里，刷新仍保持，关掉标签页失效。

## 移动端

窄屏使用同一套页面和浮动导航，工作台变成单列：

- 顶栏保留品牌、标题、主题、工作区管理和更多操作；连接状态按宽度省略。
- 连接工作流自动堆叠，按钮仍可点。
- 编辑布局时出现拖动排序面板，顺序独立保存。
- 工作区管理面板从右侧滑出，导航编辑同样可用。

## 系统横幅

| 横幅           | 何时出现                           | 处理                                                       |
| -------------- | ---------------------------------- | ---------------------------------------------------------- |
| 不安全访问提示 | 非回环地址且未使用 HTTPS           | 改用 SSH 隧道或 TLS，见[访问方式与网络](access-network.md) |
| 账号数据库状态 | 有账号正在准备、后台迁移或迁移失败 | 按提示等待或查看运行记录；不同状态会分别计数               |
| 低完整性警告   | 仅 Windows，进程完整性级别偏低     | 按提示临时或永久关闭                                       |
