# 总览

总览是登录后的第一页，路径 `/`。它把「服务状态、账号、端点、告警、主机资源」集中成可拖动的部件，并固定显示一块引导面板，告诉你当前还差哪一步。

## 页面结构

从上到下依次是：

1. 顶栏：页面标题「总览」、副标题「主机与服务状态」、连接状态徽章、主题切换、展示模式按钮、登出。
2. 工具栏：「编辑布局」/「完成」、「恢复默认」（编辑时显示）。
3. 引导面板：不是部件，位置固定，不能拖动。
4. 部件网格：默认 9 个可见部件，另有 4 个可选部件在右侧「部件库」里。

## 布局编辑

| 控件 | 作用 |
| --- | --- |
| 「编辑布局」 | 进入编辑模式，同时开启侧栏的导航编辑 |
| 「完成」 | 退出编辑模式并保存布局 |
| 「恢复默认」 | 丢弃当前布局，恢复默认部件与顺序 |
| 「部件库」区域 | 从右侧把部件拖入网格；把部件拖回部件库即移除 |

编辑模式的帮助文字分两种：

- 桌面宽度：拖动卡片移动位置、拖右下角缩放，右上齿轮改设置；把卡片拖回右侧「部件库」即可移除。
- 移动宽度：拖动手柄调整顺序，眼睛图标显隐，齿轮改设置。

把所有部件都移除后，网格位置显示空状态和「恢复默认布局」。

**保存与生效**：布局改动在编辑过程中自动保存（防抖），「完成」后落盘。保存失败时右下角出现「界面布局同步失败」提示，本地布局仍然生效——刷新后可能回到上一次成功保存的版本。

**示例**：点「编辑布局」→ 从部件库把「便签」拖进网格 → 点卡片右上齿轮输入不超过 4000 字的备忘 → 点「完成」。预期结果：刷新页面后备注仍在。

## 引导面板

引导面板用 20 个步骤描述「让机器人真正跑起来」需要做的事，只读取页面上已经有的数据，不额外请求。

它提供的主要按钮：

| 按钮 | 用途 |
| --- | --- |
| 「重新检查」 | 重新读取当前状态，刷新步骤判断 |
| 「我已打开 QQ」 | 声明 QQ 已经启动，跳过「没有 QQ 进程」这一步 |
| 「选一个 QQ」 | 打开「选择要使用的 QQ」对话框，一次只接一个账号 |
| 「连接这个 QQ」 | 打开「连接这个 QQ？」确认，然后向该进程注入接入组件 |
| 「检查一下」 | 检查管道/连接是否就绪 |
| 「我已登录，检查一下」 | 你已在 QQ 窗口完成登录后，重新检测登录状态 |
| 「去设置」 | 跳到相关设置页 |
| 「查看原因」 | 打开详情弹窗，说明失败原因 |
| 「再试一次」/「重新连接」 | 重试当前步骤 |

关键提示：详情弹窗的完成状态会写明**控制台不会自动回复消息**，并且「连接状态显示正常，只说明服务在监听或已连上」。

**遇到读取失败时**：任何资源读取失败都会优先显示错误与「当前显示上次成功读取的数据」提示，引导不会把失败当成成功继续往下走。

## 部件一览

| 部件 | 默认可见 | 最小尺寸 | 内容 |
| --- | --- | --- | --- |
| 服务状态 | 是 | 2×1 | 整体服务健康 |
| 在线账号 | 是 | 2×1 | 已登录账号数量 |
| 进程注入 | 是 | 2×1 | 已接入的 QQ 进程数，可跳到「QQ 连接」 |
| 主机名 | 是 | 2×1 | 当前主机名 |
| 系统运行 | 是 | 2×1 | 服务运行时长 |
| OneBot 连接 | 是 | 3×3 | 按账号列出的端点与状态 |
| 最近告警 | 是 | 3×3 | 来自日志流的告警/错误 |
| 主机资源 | 是 | 4×3 | CPU、内存、运行时资源 |
| 在线会话 | 是 | 3×3 | 已登录的账号会话列表 |
| 便签 | 否 | 2×2 | 自用备忘，最多 4000 字 |
| 链接卡 | 否 | 2×1 | 自定义跳转卡片 |
| 账号快捷卡 | 否 | 2×1 | 固定显示某个 UIN 的摘要 |
| 最近投递 | 否 | 3×3 | 最近的通知投递记录 |

统计类部件（服务状态、在线账号、进程注入、主机名、系统运行）没有齿轮，不可配置。

### 可配置部件与其选项

| 部件 | 可调项 | 默认 |
| --- | --- | --- |
| 最近告警 | 「显示条数」、「显示级别」 | 5 条，`warn` + `error` |
| 在线会话 | 「排序」（最近 / UIN / 昵称）、「筛选（昵称 / QQ 号）」 | 按最近 |
| 主机资源 | 「显示的指标」（CPU / 内存 / 运行时） | 全开 |
| OneBot 连接 | 「筛选（账号昵称 / QQ 号）」、「仅显示异常端点」、「排序」（默认 / 名称 / 状态） | 默认排序 |
| 便签 | 「便签内容（纯文本，保留换行）」，最多 4000 字 | 空 |
| 链接卡 | 「标题」（≤60 字）、「链接（http/https）」、「图标」 | URL 必须是 `http://` 或 `https://` |
| 账号快捷卡 | 「QQ 号」 | 空 |

链接卡只接受 http/https，避免 `javascript:` 之类可执行的地址。

### 统计数字的诚实表现

- 读取失败且没有缓存时显示 `—`。
- 读取失败但有缓存时显示旧数字，并标注「更新失败，显示上次数据」。

这两条是刻意的：界面不会用一个编造的数字盖住错误。

### OneBot 连接部件的状态词

| 状态 | 含义 |
| --- | --- |
| 正常 | 端点在工作（监听中或已连接） |
| 注意 | 有近期错误但服务仍在 |
| 异常 | 监听或连接失败 |
| 应用失败 | 配置已保存，但热重载失败 |
| 未启用 | 节点被关闭 |

端点类型显示为「HTTP 服务端」「HTTP 上报」「WS 服务端」「WS 客户端」，和 [节点配置](onebot-config.md) 的四个页签一一对应。

## 导航与侧栏

侧栏包含品牌块、版本号、`OneBot v11 控制台` 说明和六个导航项：

| 导航 | 页面 | 副标题 |
| --- | --- | --- |
| 总览 | `/` | 主机与服务状态 |
| QQ 连接 | `/processes` | 连接 / 断开 / 登录 |
| 节点配置 | `/config` | OneBot 协议端点 |
| 日志 | `/logs` | 实时事件流 |
| 调试 | `/debug` | 测试台与实时活动 |
| 系统设置 | `/settings` | 主题与账号 |

规则：

- 「总览」与「系统设置」是钉住的：可以排序，**不能隐藏**。如果隐藏总览，就没有入口再打开布局编辑，会把自己锁死。
- 其余四项可以隐藏和排序。「调试」默认可见，但它不在存储的默认列表里，而是由布局校正常规追加的——所以它属于「默认可见、可隐藏」。
- 侧栏可以折叠成图标栏，鼠标悬停自动展开；「钉住侧栏展开」是桌面宽度下的设置项（在「外观」里）。

### 编辑导航

在编辑布局状态下，侧栏会进入「编辑导航」模式：拖动行排序，逐项开关显隐，点「完成」退出。

### 侧栏更新提示

检测到新版本时侧栏出现「有新版本 v{版本} · 点击查看」，点击跳到「系统设置 → 关于」。更新检查被关闭时不会出现这一行。

## 顶栏

| 元素 | 作用 |
| --- | --- |
| 连接状态徽章 | 控制台会话状态（**不是** QQ 在线状态） |
| 主题切换按钮 | 浅色 / 深色 |
| 展示模式按钮 | 进入或退出展示模式 |
| 登出 | 弹出「确认登出？」后清除会话 |

这三个元素可以在「外观 → 顶栏」里分别关掉；「登出」始终存在。

## 展示模式（kiosk）

适合挂在墙上的大屏或值班台：

- 进入方式：点顶栏的展示模式按钮，或在地址后加 `?kiosk=1`。
- 退出：按 `Esc`。
- 状态记在浏览器会话里，刷新仍保持，关掉标签页即失效。
- 效果是隐藏界面外壳（例如总览的编辑入口），**只影响显示，不影响认证**，也不会让未登录的人看到数据。

## 移动端布局

窄屏下列表改成单列，顺序与显隐独立于桌面网格：手机上调过的顺序不会改掉桌面的摆法。编辑方式变成「拖动手柄 + 眼睛 + 齿轮」。

## 系统级横幅

| 横幅 | 何时出现 | 处理 |
| --- | --- | --- |
| 不安全访问提示 | 非回环地址 + 非 HTTPS | 用 SSH 或 TLS，见 [访问方式与网络](access-network.md) |
| 账号数据库状态 | 有账号数据库正在准备、迁移或迁移失败 | 按提示等待或查看日志；失败可用/不可用会在横幅里分开计数 |
| 低完整性警告 | 仅 Windows，进程完整性级别偏低 | 「临时关闭」或「永久关闭」 |

## 示例：从空模板搭一个值班视图

1. 点「编辑布局」。
2. 移除「便签」以外的可选部件，把「OneBot 连接」和「主机资源」拖到第一行。
3. 给「OneBot 连接」打开「仅显示异常端点」。
4. 点「完成」，再点顶栏展示模式按钮。
5. **预期结果**：只剩运维关心的两块数据，没有导航和工具栏；按 `Esc` 能回到完整界面。

## 保存与失败恢复

| 动作 | 保存方式 | 失败表现 |
| --- | --- | --- |
| 布局、部件设置、移动端顺序 | 自动保存到界面配置 | 右下角「界面布局同步失败」；本地仍生效 |
| 顶部导航显隐 | 同上 | 同上 |
| 引导步骤状态 | 不落盘，按实时数据计算 | 读取失败时显示错误，不会跳过 |

布局被改坏时最省事的恢复是「恢复默认」；如果连页面都进不去，用 `?safe-mode=1` 排除自定义 CSS 的问题，见 [系统设置：Nowluma 与平台](settings-runtime.md#高级)。
